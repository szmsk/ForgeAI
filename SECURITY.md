# Security Policy

## Scope

ForgeAI executes repository code and therefore treats repositories, pull requests and build artifacts as untrusted input.

This project is a portfolio reference implementation. Before exposing it to untrusted internet traffic, review `docs/THREAT_MODEL.md` and `docs/PRODUCTION.md` and deploy the sandbox workers separately from the control plane.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Until a private security contact is configured for this repository, report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature.

Include:

- affected component
- reproduction steps
- security impact
- suggested mitigation, if known

Do not include real credentials, tokens or private customer data in reports.
